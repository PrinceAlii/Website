# Fonts

This directory vendors the open-source Geist family from
[vercel/geist-font](https://github.com/vercel/geist-font):

- `Geist-Variable.woff2`: Geist Sans variable, weights 100 to 900
- `GeistMono-Variable.woff2`: Geist Mono variable, weights 100 to 900
- `GeistPixel-Square.woff2`: Geist Pixel Square, weight 500

The font software is licensed under the SIL Open Font License, Version 1.1.
See `OFL.txt` for the license and `AUTHORS.txt` for attribution.

The filenames are local aliases only. The font files themselves are unmodified.
